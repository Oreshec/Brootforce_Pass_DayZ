# Brootforce_Pass_DayZ

Брутфорс-автоматизатор импульсного замка для DayZ. Чистый CPython,
**ноль pip-зависимостей** — только стандартная библиотека + `ctypes`.

Программа двигает колёса замка одним действием за раз: скан-коды через
`SendInput` (их видят игры на DirectInput/RawInput), точные тайминги,
мгновенная остановка по `Ctrl+C`.

Файл программы: **`Brootforce_Pass_DayZ2.py`**

---

## Механика замка

- Клавиша взаимодействия (по умолчанию `f`) **кликом переводит фокус** на
  следующее колесо по кольцу. Кольцо замкнутое: полный круг = `N` кликов.
- **Зажатие** вращает только колесо в фокусе: `+1` цифра за `step_time`.
- Колёса **полностью независимы**: вращение одного не двигает соседние
  (никакого автопереноса и сброса младших разрядов).
- Игра проверяет код непрерывно — пока колесо показывает код, проходя
  позицию.

### Алгоритм: одометр

Перебор идёт как одометр — каждый шаг это `+1` ко всему коду. Инвариант
перед каждым шагом: фокус на колесе единиц.

1. **Единицы** получают зажатие — всегда `+1`.
2. Если единицы переполнились (было `9`) — старшим колёсам тоже даётся по
   зажатию, по одному: `click` (смена фокуса) + `hold` (`+1`).
   Глубина переноса = число хвостовых девяток.
3. **Возврат фокуса** на единицы — `N − depth` кликов (клик двигает фокус
   только к старшим колёсам с заворотом).

Никакого «прокрутить все 10 цифр и переехать на старший разряд». Каждый
код посещается ровно один раз — покрытие проверено на модели для `N=1,2,4,6`.

## Требования

- Windows 10/11, Python 3.10+.
- Терминал запускать **от имени администратора**: при включённом UIPI ввод
  в игру, запущенную с правами администратора, молча отбрасывается.
- Никаких `pip install`. `pynput` и подобные библиотеки **не используются**
  (виртуальные коды игра игнорирует, ей нужны скан-коды).

## Порядок проверки

1. **Проверка, что игра видит ввод** (от администратора):
   ```powershell
   python Brootforce_Pass_DayZ2.py --test
   ```
   3 клика и зажатие 1 с — переключитесь в игру и убедитесь, что замок
   реагирует.

2. **Калибровка `--step-time`** — самый важный параметр. Значение по
   умолчанию `0.6` это предположение, не измерение:
   ```powershell
   python Brootforce_Pass_DayZ2.py --probe "h0.6"
   ```
   Сколько цифр прошло колесо за зажатие? Если прошло 3 вместо 1 —
   зажатие в 3 раза длиннее нужного, подставьте `--step-time 0.2`.

3. **Пошаговый прогон** — произвольная последовательность действий:
   ```powershell
   python Brootforce_Pass_DayZ2.py --probe "c c h0.6 p0.4"
   ```

4. **Боевой запуск** (от администратора):
   ```powershell
   python Brootforce_Pass_DayZ2.py --digits 4 --step-time 0.2
   ```

## CLI

| Флаг | Назначение |
|------|------------|
| `--digits N` | число цифр замка (по умолчанию `4`) |
| `--key K` | клавиша взаимодействия (по умолчанию `f`) |
| `--step-time S` | зажатие = `+1` цифра, с (по умолчанию `0.6`, **калибровать!**) |
| `--start-code B` | начальный код (по умолчанию `0`) |
| `--probe SEQ` | пробник: `c c h1.5 p0.4` (`c`/`к` = клик, `h`/`з` = зажатие, `p`/`п` = пауза) |
| `--probe-pause S` | пауза между действиями пробника, с (по умолчанию `0.3`) |
| `--test` | 3 клика + зажатие 1 с — проверка ввода |
| `--dry-run` | без реального ввода |

## Остановка

`Ctrl+C` — корректно останавливает, снимает все зажатые клавиши.

## Архитектура

- `CrackerConfig` — frozen dataclass, валидация в `__post_init__`.
- `CancellationToken` — прерываемый точный сон (`check` / `sleep` /
  `sleep_precise`) вместо глобальных флагов.
- `KeyActor` — Protocol (`click` / `hold` / `release_all`), инверсия
  зависимостей.
- `SendInputKeyActor` — боевой ввод скан-кодами, трекинг зажатых клавиш.
- `DryRunKeyActor` — ничего не отправляет, мгновенно.
- `Odometer` — только бизнес-логика вращения.
- `carry_levels(code)` — глубина переноса (число хвостовых девяток).

### Технические детали ввода

- `SendInput` + `KEYEVENTF_SCANCODE` (Set 1); буквы/цифры —
  `MapVirtualKeyW(VK, MAPVK_VK_TO_VSC)`, спецклавиши — таблица,
  extended-клавиши — флаг `KEYEVENTF_EXTENDEDKEY`.
- В union `INPUT` включён `MOUSEINPUT`: без него `sizeof(INPUT)` на x64
  неверный (40 байт) и `SendInput` молча сбоит.
- `press`/`release` парой, `release` — всегда в `finally`, чтобы клавиша
  не «залипала» при ошибке или отмене.
